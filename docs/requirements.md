# Requirements

## Problem
Finding the right nearby hospital, clinic or diagnostic lab in India is harder than it should be, especially for
people who aren't comfortable with technology. Information is spread across government portals, maps and private
apps, and it's hard to tell government from private facilities or which ones offer emergency care.

## Solution
One simple search that understands plain English or Hindi, shows matching facilities on a list and map, and is honest
about where each piece of information came from and how fresh it is.

## Users
Ordinary people and families looking for care; caregivers searching for elderly relatives; people new to a city.
No technical knowledge assumed.

## User stories

| ID | Story | Acceptance criteria |
|----|-------|---------------------|
| US1 | I type "government hospital with emergency in Lucknow" and see matching hospitals on a list and a map. | Correct filters on ≥90% of the evaluation set; results in under 5 s once the server is awake |
| US2 | I search near a pincode or my current location. | Sorted by distance; location used for that search only, never stored |
| US3 | I see the address, phone, directions, data source and last-updated date. | Every field comes from the database; source shown on every listing |
| US4 | If I type an emergency ("chest pain", "accident"), I see 112 / 108 first. | 100% of emergency evaluation cases caught by the code check, without the LLM |
| US5 | I can ask "What is NABL?" and get a short, simple answer. | Uses only the glossary cards and shows its source; under 120 words |
| US6 | I can ask in Hindi or Hinglish. | ≥80% correct filters on the Hindi/Hinglish subset |
| US7 | I can report wrong information. | Stored without personal data; rate-limited |
| US8 | If I ask a medical question, I'm told politely that this app can't advise and how to find a doctor. | No diagnosis or treatment advice in any evaluation case |

## Non-functional requirements

| Area | Requirement |
|------|-------------|
| Privacy | No accounts; location used per search and never stored; users asked not to type personal health details |
| Safety | Emergency banner always visible; no medical advice; listings never generated by the LLM |
| Attribution | "© OpenStreetMap contributors" and data.gov.in credits in the app and README |
| Security | Keys only in secrets; SQL built by code with bound parameters; input length capped; rate limits; API key between UI and API |
| Cost | $0: free tiers only; one small LLM call per question |
| Usability | Mobile-first, one search box, English and Hindi |

## Scope
**In (v1):** hospitals, clinics and labs across India; search by city, pincode or location; filters for type,
government/private and emergency; glossary of common terms.

**Out (v1):** doctors, prices, bookings, reviews, accreditation filters (after a terms check), lab-report explanations.
