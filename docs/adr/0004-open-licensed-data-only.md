# ADR 0004: Open-licensed data only
- Status: Accepted · Date: 2026-10-26

**Context:** commercial directories (Google Maps, Practo, Justdial) forbid copying; doctors' details are personal data.
**Decision:** use OpenStreetMap (ODbL) and data.gov.in (GODL-India) with attribution; link to accreditation sources
instead of copying them; no personal data.
**Consequences:** coverage and freshness depend on open data; every listing shows its source and date.
