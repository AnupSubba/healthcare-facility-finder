# Data sources and licences

| Source | Used for | Licence and conditions |
|--------|----------|------------------------|
| OpenStreetMap via the Overpass API | Hospitals, clinics and labs with coordinates | ODbL. Credit "© OpenStreetMap contributors". If the combined database is published, share it under ODbL. Overpass is shared: one state per request, cache, pause between requests |
| data.gov.in datasets (download the CSV) | Government hospital / health-facility directories | Government Open Data License - India: reuse with attribution. Record each dataset's title, URL and download date below |
| Nominatim (OpenStreetMap geocoder) | Coordinates for records without them | Usage policy: max 1 request/second, identify the app (CONTACT_EMAIL), cache results, credit OSM |
| Glossary cards in `knowledge/` | Explanations of NABH, NABL, PM-JAY, CGHS, etc. | Own work, MIT; each card links to the official page |

**Not used:** Google Maps/Places data, Practo, Justdial (terms forbid copying); doctors' personal details.
NABH / NABL / PM-JAY lists will only be used after checking their terms, storing just a status and a link.
